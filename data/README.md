# Data Directory

This directory contains data files generated by the pipeline scripts.

## Files

| File | Generated by | Description |
|---|---|---|
| `spotify_interactions.csv` | `scripts/prepare_data.py` | ~5,000 SpotifyCares customer-reply pairs from the Kaggle dataset |
| `train_set.csv` | `scripts/build_golden_set.py` | ~4,800 pairs for TF-IDF retrieval (golden examples excluded) |
| `golden/golden_set.jsonl` | `scripts/build_golden_set.py` | 200 heuristically-labelled evaluation examples |
| `golden/labeling_guide.md` | (committed) | Intent definitions, escalation rules, edge case guide |

## How to Reproduce

```bash
python scripts/prepare_data.py     # Downloads from Kaggle (requires internet)
python scripts/build_golden_set.py # Creates train_set + golden_set
```

## Note on Versioning

`spotify_interactions.csv` and `train_set.csv` are excluded from git (large files).
`golden/golden_set.jsonl` IS committed — it is the fixed evaluation set and must not change.
